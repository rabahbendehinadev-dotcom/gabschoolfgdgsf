أريد تجهيز هذا المشروع للنقل من Replit إلى VPS عبر Dokploy بدون توقف وبدون ضياع أي بيانات أو صور.

المطلوب:

1. تأكد أن آخر نسخة مستقرة من المشروع موجودة في branch اسمه main، ولا تحذف أو تغيّر أي بيانات حالية.

2. أنشئ Dockerfile احترافي لتشغيل المشروع في Production، مع:
- تثبيت dependencies
- build للواجهة إذا كانت موجودة
- تشغيل السيرفر الصحيح
- استخدام PORT من متغيرات البيئة
- Healthcheck
- عدم تخزين قاعدة البيانات أو الصور داخل Docker image

3. أنشئ ملف docker-compose.yml مناسب للتشغيل المحلي والاختبار، لكن اجعل المشروع قابلاً للربط مع PostgreSQL خارجي في Dokploy من خلال DATABASE_URL.

4. اجمع جميع متغيرات البيئة المطلوبة في ملف:
.env.example
بدون وضع كلمات المرور أو المفاتيح الحقيقية داخله.

5. افحص جميع الأماكن التي تستعمل Replit Database أو Replit Object Storage أو أي خدمة خاصة بـ Replit، واستبدل الربط المباشر بطبقة إعدادات تعتمد فقط على متغيرات البيئة.

6. الصور والملفات الحالية مهمة جداً:
- لا تحذف ولا تنقل أي ملف الآن.
- أنشئ Script آمن لتصدير جميع الصور والملفات من Replit Object Storage.
- أنشئ Script آخر لاستيرادها إلى التخزين الجديد في VPS.
- حافظ على أسماء الملفات والمسارات والروابط المرتبطة بها في قاعدة البيانات.
- لا تغيّر روابط الصور قبل نجاح الاستيراد والتحقق منها.
- أعطني تقريراً بعدد الملفات، حجمها، والملفات التي فشل نقلها إن وجدت.

7. قاعدة البيانات مهمة جداً:
- أنشئ طريقة Backup كاملة لقاعدة PostgreSQL الحالية بصيغة pg_dump.
- أنشئ أوامر Restore على PostgreSQL في Dokploy.
- لا تنفذ أي حذف أو Reset أو Migration مدمرة.
- تأكد أن migrations آمنة ولا تعيد إنشاء الجداول أو تمسح البيانات.
- أعطني عدد السجلات في أهم الجداول قبل وبعد النقل للتحقق.

8. أنشئ ملف MIGRATION.md يحتوي بالترتيب على:
- رفع المشروع إلى GitHub branch main
- إنشاء PostgreSQL في Dokploy
- إضافة متغيرات البيئة
- Restore لقاعدة البيانات
- نقل الصور والملفات
- تشغيل المشروع
- اختبار الصور وتسجيل الدخول والفيديوهات والإشعارات
- تغيير الدومين فقط بعد نجاح جميع الاختبارات
- إبقاء Replit شغالاً حتى التأكد النهائي

9. اختبر Docker build محلياً وتأكد أن المشروع يشتغل بدون أي اعتماد مباشر على بيئة Replit.

10. لا تغيّر منطق المشروع ولا الواجهة ولا الميزات. المطلوب فقط تجهيز آمن للنقل إلى VPS.

في النهاية أعطني:
- قائمة الملفات التي أنشأتها أو عدلتها
- الأوامر التي سأستعملها
- المخاطر التي وجدتها
- الأشياء التي تحتاج نقل يدوي
- تأكيد واضح أن الصور وقاعدة البيانات لن تضيع أثناء النقل
